🎯 What is this tool?

EBRO Scrap Form Processor turns photos or scans of EBRO "Control Calidad" forms into clean, structured Excel reports. It uses an AI vision model to read the handwriting on each form, validates the result, and lets you review and correct it before exporting.

🔒 Your data stays private. Images go directly from your browser to the AI provider you choose. There is no server, no tracking, and no build step.

🚀 Quick Start

  1. Pick an AI platform (Gemini or DeepSeek) and paste your API key.
  2. Choose an input mode — Upload (drag & drop) or Local Folder (Chrome/Edge/Opera only).
  3. Add your images. The app auto-converts HEIC, fixes rotation, and compresses each file.
  4. Processing starts automatically (if Auto-process is checked) as soon as the first image is ready.
  5. Review the results — click Edit on any row to fix fields against the original image.
  6. Download the Excel with the green Download Merged Excel button.

📥 Input Modes

📤 Upload mode (works everywhere)

  • Drag & drop images onto the drop zone, or click to browse.
  • Set a Path Prefix (e.g. c/download/) — it gets prepended to the _file column in the export.
  • Best for: one-off batches, phones, non-Chrome browsers.

📁 Local Folder mode (Chrome / Edge / Opera)

  • Authorize three folders: Input, Readed, and Error.
  • Input — where unprocessed forms live.
  • Readed — where successful forms are moved (converted to .jpg).
  • Error — where failures land so you can inspect and retry.
  • Each processed file is written to its target folder and the original is deleted.
  • Folder handles are remembered — you only need to re-grant permission once per session.
⚠️ Local Folder mode is unavailable on Firefox and Safari. The Folder tab will be disabled.

⏳ Processing

  • Auto-process — starts the AI as soon as the first image is compressed, so large batches never sit idle.
  • Queue — shows every file with its thumbnail, resize stats, and live status.
  • Rate limiting — requests are throttled to ~15 per minute by default.
  • Retries — network errors, 429s, and 503s are retried up to 3 times with backoff (5s → 10s → 20s).
  • Wake Lock — the screen stays awake while processing so long runs aren't interrupted.

✏️ Editing Forms

Click Edit on any row in the results table to open the side-by-side editor.

  • Left pane — the original image with pan, zoom (Ctrl + wheel), rotate (↺ ↻), Fit W, Fit H, and 1:1 controls.
  • Right pane — every extracted field, grouped by section.
  • Edited fields turn green and show the AI's original value underneath.
  • Signatures and ticket category become dropdowns.
  • Changes are only saved when you click 💾 Save changes.

📚 Correction Library

The app learns from your edits. When you fix a field and save, the pair (wrong AI value → your correct value) is recorded.

  • After the same correction is seen 2 or more times, it becomes ACTIVE.
  • Active corrections are applied automatically to future extractions.
  • Open the library with the 📚 View Corrections button in the results header.
  • You can delete individual entries or clear the whole library at any time.
💡 The library lives only in this browser. Clearing your browser data will erase it.

🛠 Troubleshooting

SymptomFix
"Browser does not support File System Access API" Use Chrome / Edge / Opera over http(s)://, or switch to Upload mode.
Frequent "INVALID_IMAGE" errors The AI decided the photo isn't a Control Calidad form. Retries are intentionally disabled for these.
Repeated 429 / 503 errors You hit the model's rate limit. Switch to a Flash-Lite model or a paid tier.
Folders must be re-authorized every session Browsers reset folder permissions on reload. One click per folder per session.
Queue stuck on "Waiting" The consumer hasn't started. Click 🚀 Start Batch / Process & Move.
Balance panel stays empty Only DeepSeek exposes a balance endpoint. Gemini doesn't.
Tip: press Esc to close
